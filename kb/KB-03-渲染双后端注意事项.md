# KB-03 渲染双后端注意事项

> 深度阅读：`documents/VulkanBackendReview.md`（A-F 正确性 + P0-P3 性能）、`documents/VULKAN_FIXES.md`（修复台账）、`documents/VULKAN_BACKEND.md`（启用指南）、`documents/LIGHTING_ASSESSMENT.md`（光照现状与 2b 依赖）。

## 后端拓扑

- OpenGL 默认；Vulkan 1.3 可选编译；`Renderer::SetAPI` 运行时切换。三层抽象：`RendererAPI`（接口）→ `RenderCommand`（分发）→ `Renderer`（场景级语义）。
- **架构债（E1）**：公共接口有 OpenGL-first 渗漏——`BeginScene` 的 Y 翻转 hack、GLSL 重写桥接。新代码不要加深渗漏；收敛方向见 ROADMAP 2b（SPIR-V 反射 + RenderPassDesc + 资源屏障抽象）。

## OpenGL 侧

- shader 是 GLSL，纹理加载 UV 方向按 GL 翻转假定（assimp 导入未用 `FlipUVs`，个别格式可能需 per-format 调整——改这里前先读 ROADMAP 技术债清单）。

## Vulkan 侧（正确性 A-F，修前必读台账确认现状）

| 项 | 坑 | 修法方向 |
|---|---|---|
| A | pipeline 缓存不随 swapchain 重建清空 → device lost | RecreateSwapchain 时销毁重建 pipeline |
| B | 无帧内延迟销毁 → use-after-free | per-frame deletion queue，fence 信号后销毁 |
| C | `RequestResize` 死代码 | 接入 window resize 回调 |
| D | `VK_CHECK` release no-op | release 也要记日志+降级 |
| E | 反射式 UBO 靠 regex+手算 std140，覆盖不全 | 短期补 case，长期 SPIRV-Reflect |
| F | 未绑定 sampler 槽 descriptor 留空 → validation 报错 | 全局 dummy texture（1×1） |

**任何 Vulkan 修改动手前先查 `VULKAN_FIXES.md`：A-F 中某些可能已修（台账为准），别重复修也别假设已修。**

## Vulkan GLSL 限制（与 OpenGL GLSL 不完全通用）

- 需要显式 `in/out` 声明；不支持 sampler 数组写法。同一 shader 源要两后端可用时，注意这些差异（现状是 shader 目录按后端区分）。
- GPU 资源（Buffer/Image/Pipeline）**必须在 Shutdown 前显式释放**，不能靠进程退出回收。

## 性能已知项（P0-P3）

- P0：descriptor 逐 draw 分配、`ImmediateSubmit` 全 stall。P1：VertexArray 每 draw 堆分配 + dynamic_pointer_cast、PipelineCache 不落盘。
- 优化前先 Profiler（F1 面板）取证，禁止凭感觉优化。

## 光照现状

- Blinn-Phong 前向：1 方向光 + 16 点光 + 8 聚光 + 环境光。阴影/PBR/IBL/延迟渲染（阶段 C）依赖 2b 收敛，**不要跳过 2b 直接做**（LIGHTING_ASSESSMENT 结论）。
