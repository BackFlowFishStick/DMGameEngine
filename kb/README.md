# kb — Agent 知识库

> kb 的定位：**把已经踩过的坑变成一次性成本**。每条 KB 是某个领域"不读会返工"的最小必知集。
> kb 与 documents/ 的分工：kb 是蒸馏后的速查（短、结论式、带跳转）；documents/ 是完整档案（设计推导、事故全过程）。
> 与 playbooks/ 的分工：kb 回答"这里的规则和坑是什么"；playbook 回答"做这类任务的步骤"。

## 维护规则

1. **KB-07 是活文档**：任何 Agent 遇到"调试 > 30 分钟且根因非显然"的问题，修复后必须追加条目（格式见该文件头部）。
2. 领域 KB（KB-01~06）由对应主责 Agent 增量追加小节；结构性调整归文档 Agent。
3. 条目必须可证伪：写清楚"现象 → 根因 → 规则"，不写"注意性能"这类空话。
4. 发现 KB 与代码事实不符 → 立即修正并在条目尾注明"2026-xx-xx 核验"。
