新增 playbook 的规则（文档 Agent 维护）：
- 同类任务手工做过 2 次以上、且步骤里有非显然的判断点，才值得沉淀为 playbook。
- 编号顺延；文件名用中文（与现有文档风格一致）；必须在索引表登记。
