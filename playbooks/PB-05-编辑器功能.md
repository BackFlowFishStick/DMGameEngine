# PB-05 编辑器功能

> 背景：editor/ 是独立 exe（dllimport 引擎），ImGui 多视口，Unity 风格布局。
> 路线图：`editor/EDITOR_ROADMAP.md` 阶段 2-5。已完成：Viewport/Hierarchy/Inspector/CRUD/save-load/Play-Pause/Asset Browser 基础版/LogPanel。

## 前置

1. 编辑器只是引擎的消费者：**能用引擎 API 实现的，绝不绕过 API 摸引擎内部**。发现 API 缺口（如某个类没导出导致 LNK2019），修法优先是补引擎侧导出/加门面接口，而不是拷源码。
2. 读 `kb/KB-02-DLL边界与STL.md`：编辑器侧最容易踩的就是跨 DLL 传 STL 与 ImGui 单 context（R1/R7）。

## 步骤

### 1. 面板类功能
- 新面板：`editor/src/Panels/` 下新建，挂到 EditorLayer；源文件注册进 `editor/CMakeLists.txt`（R2）。
- ImGui 组件选型参考现有面板写法（表格用 `ImGui::BeginTable`，拖拽用 DragFloat 系列保持手感一致）。

### 2. Viewport 交互类（gizmo/拾取/拖拽）
- 离屏 FrameBuffer → ImGui Image 的坐标换算：注意 Y 翻转与视口缩放，先例见 `editor/GIZMO_HITTEST_FIX.md`（命中检测修复记录）。
- 鼠标拾取（路线图 2a）：推荐 entity ID → 颜色附件的像素读取方案；实现要考虑 Vulkan 后端下读回的可行性（读 `kb/KB-03`）。

### 3. 数据一致性
- 编辑器改状态 → 引擎对象；Play-Pause 已有状态快照机制，新功能必须接入（Play mode 隔离是路线图阶段 4 重点）。
- 序列化只走 `SceneSerializer`，编辑器不私自写场景文件格式。

### 4. 验证
- 手工验证路径：启动 editor → 执行操作 → save → load → 状态往返一致。
- 编辑器崩溃 = 最高优先级 bug，按 PB-04 处理并记 KB-07。

### 5. 收尾
- PB-08 自检；变更日志；TASKS.md ✅。UI 大改前最好先截 before/after 图贴进变更日志（文档 Agent 转写人类文档时会用到）。
